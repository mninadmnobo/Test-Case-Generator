# Skill: Specification Coverage Verification

**Description:** 
This skill defines the process for performing a manual "Specification Coverage" analysis. It traces the explicit requirements defined in the input dataset to the output test cases generated by various AI approaches, producing a coverage matrix. This process is crucial for proving how the Agentic Pipeline suppresses test bloat compared to baselines.

## Inputs
1. **Functional Description:** `dataset/functional_description/[Dataset].md`
2. **Generated Test Cases:** `results/[Dataset]/[Model]/[Approach]/test-cases.md`

## Output
* **Coverage Matrix File:** `results/[Dataset]/specification_coverage/sc-[dataset]-[model]-[approach].md`

## Step-by-Step Process

### 1. Extract Core Requirements
*   Read the target `functional_description.md` file.
*   Break down the paragraphs into explicit, atomic, and testable requirements.
*   Number them sequentially (e.g., `REQ-01`, `REQ-02`). 
*   *Heuristic:* A simple application like SwagLab yields exactly 20 core requirements.

### 2. Map Generated Test Cases
*   Read the target `test-cases.md` file generated by the specific model approach.
*   For every requirement extracted in Step 1, scan the generated test cases to find a direct match.
*   Identify the exact Test Case ID (e.g., `TC-004`) and Title that fulfills the requirement.

### 3. Generate the Markdown Matrix
*   Create a new file in the `specification_coverage` folder following the naming convention: `sc-[dataset]-[model]-[approach].md`.
*   Create a markdown table with four columns: 
    *   `Req ID`
    *   `Functional Description (From [Dataset].md)`
    *   `Mapped Generated Test Case (From [approach]/test-cases.md)`
    *   `Status`
*   Populate the table. Use `✅ Covered` for exact matches, and `⚠️ Partial/Missed` if no valid test exists.

### 4. Provide Thesis Analysis
*   Calculate the total coverage percentage (e.g., 19/20 = 95%).
*   Write a brief summary below the table highlighting the coverage rate.
*   **Crucial Step:** Relate the findings to the thesis. Compare the total number of tests generated by the Baseline vs. the Pipeline. 
    *   *Example:* If the Baseline hits 100% coverage but generates 105 tests, while the Pipeline hits 95% coverage but generates 88 tests, highlight how the Pipeline successfully traded 5% edge-case coverage to suppress massive hallucinated bloat.
