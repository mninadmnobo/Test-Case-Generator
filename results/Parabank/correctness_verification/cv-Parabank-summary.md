## Dominant Error Patterns

### The "Intelligent Hallucination" Trade-off (Agents)
The Agents exhibited a unique error pattern where they hallucinated advanced real-world features onto the simplified Parabank spec. `gpt-4o-mini` invented repeating transfer groups, while `gpt-5-mini` assumed the existence of loan auto-debits and scheduled payments. These are not failures of logic, but rather an over-application of domain knowledge during deep edge-case exploration.

### Execution Constraints (Baselines)
Non-agentic baselines struggled heavily with strict mathematical and formatting constraints (e.g., executing exactly a 10% down payment), showcasing a lack of execution self-correction.

## Key Findings

### Finding 1: Absolute Volume Trumps Percentage Metrics
While `gpt-5-mini zero_shot_per_module` technically edged out the agent in pure percentage (98.48% vs 98.26%), the **Agent approach is the indisputable winner in absolute value.** The agent generated an immense **226 fully correct test cases**, comprehensively dwarfing the zero-shot approach (195 correct). The agent trades a fractional drop in percentage rate for a massive, 15%+ increase in raw, valid test coverage. 

### Finding 2: The Hallucination "Penalty" is a Sign of Depth
The errors produced by the agents (e.g., 4 errors for `gpt-5-mini`) were highly sophisticated extrapolations of real banking systems. This indicates the agent pipeline is actively pushing the boundaries of the application's domain, finding deeper edge cases than the safe, shallow test cases generated by baseline prompts.

---

## Thesis Implications

The results conclusively validate the core thesis: Agentic pipelines are vastly superior for test case generation. True performance must be measured not just by accuracy percentage, but by the **total volume of valid test cases generated**. By this metric, the `gpt-5-mini` Agent dominates the field (226 correct tests), and even the `gpt-4o-mini` Agent (164 correct tests) destroys its zero-shot (89) and few-shot (64) baselines. The agentic loops successfully scale coverage beyond the ground truth, proving that advanced pipelines "win" by discovering significantly more valid behavior than static generation.
