# Coverage Report: gpt-5-mini vs Ground Truth

## 1. Executive Summary

This report provides a detailed gap analysis between the 200 ground truth test cases for the ParaBank React/TypeScript application and the 230 test cases generated by the `gpt-5-mini` agent. 

**Overall Coverage:** The agent successfully covered **183 out of 200** Ground Truth (GT) scenarios, achieving a **91.5% coverage rate**. The `gpt-5-mini` model demonstrated exceptional depth in boundary and edge case testing, actually producing more unique test conditions (230) than the ground truth suite. However, it still missed a few specialized edge cases regarding security payloads, extreme negative values, and session timeouts.

## 3. Gap Analysis

### Login
**Missing Scenarios (Present in GT, missed by Agent):**
* MW-LOGIN-002: Valid login with username (Agent only tests email input for the username field).
* MW-LOGIN-014: Login with extremely long email (> 255 chars).
* MW-LOGIN-015: SQL injection in email (`' OR 1=1 --`).

**Extra Scenarios (Present in Agent, not in GT):**
* TC-010: Password one character below minimum length is blocked.
* TC-011: Password missing required special character is blocked.

### Register
**Missing Scenarios (Present in GT, missed by Agent):**
* MW-REG-026: Registration session timeout (leaving page open for 30 mins before submit).

**Extra Scenarios (Present in Agent, not in GT):**
* TC-018: Phone_Number typed as 10 continuous digits is automatically formatted.
* TC-021: Pressing browser Back shows the registration form blank (preventing duplicate submission).

### Accounts Overview
**Missing Scenarios (Present in GT, missed by Agent):**
* MW-AO-008: Zero balance display ($0.00 without negative sign).
* MW-AO-009: Extreme negative balance rendering without UI breakage.

**Extra Scenarios (Present in Agent, not in GT):**
* TC-010: Table ordering when multiple accounts share the same Open_Date (same-day boundary).
* TC-011: Table ordering for Open_Date one day apart.
* TC-013: Clicking the Account Number link once and rapidly multiple times.

### Open New Account
**Missing Scenarios (Present in GT, missed by Agent):**
* *None. Agent covered 100% of GT.*

**Extra Scenarios (Present in Agent, not in GT):**
* TC-016: Funding source balance exactly equals deposit amount.
* TC-018: Initial_Deposit_Amount entered with excessive decimal precision.
* TC-019: Rapid re-submission after successful open (back-button duplicate prevention).

### Transfer Funds
**Missing Scenarios (Present in GT, missed by Agent):**
* MW-TF-016: External routing number boundaries (< 9 or > 9 digits).

**Extra Scenarios (Present in Agent, not in GT):**
* TC-018 & TC-019: Advanced edge cases around highly precise decimal amounts and rapid consecutive transfer submissions.

### Payments

**Extra Scenarios (Present in Agent, not in GT):**

### Request Loan
